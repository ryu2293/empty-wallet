# 텅빈지갑 (Empty Wallet) - 개발 스펙 v3

## 프로젝트 개요
소비 습관 교정 앱. 사용자가 목표를 설정하면 다람쥐 캐릭터 AI 페르소나가 소비 상태에 따라 반응하며 퀘스트를 통해 소비 습관을 교정해준다.

## 기술 스택
- **프레임워크**: Flutter Web
- **로컬 저장소**: shared_preferences
- **서버**: 없음 (더미 데이터)
- **DB**: 없음
- **실행**: flutter run -d chrome

## 화면 1: 목표 설정 (OnboardingScreen)

앱 최초 실행 시에만 표시. shared_preferences에 goal_name이 없으면 이 화면으로 이동.

캐릭터 이미지 (character_happy.png)

입력 카드 (배경: #EDE0C4, borderRadius: 16)

## 시연 모드 상태 관리 (demo_data.dart)

```dart
class DemoState extends ChangeNotifier {
  int _step = 0;
  int get step => _step;

  void nextStep() {
    _step = (_step + 1) % 3;
    notifyListeners();
  }
}
```

## QuestItemWidget 상세

```dart
Widget build(BuildContext context) {
  return Padding(
    padding: EdgeInsets.symmetric(vertical: 6),
    child: Row(
      children: [
        // 체크 아이콘
        Icon(
          checked ? Icons.check_circle : Icons.radio_button_unchecked,
          color: checked ? #5C9E6B : #8D6E63,
          size: 20,
        ),
        SizedBox(width: 8),

        // 퀘스트 내용
        Expanded(
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              // isModified일 때 이전 퀘스트 취소선 표시
              if (isModified)
                Text(oldText,
                  style: TextStyle(
                    decoration: TextDecoration.lineThrough,
                    color: #8D6E63,
                    fontSize: 12,
                  )
                ),
              Text(text, style: TextStyle(fontSize: 14, color: #3E2723)),
              Text(subText, style: TextStyle(fontSize: 12, color: #8D6E63)),
            ],
          ),
        ),

        // 보상/페널티
        Text(reward,
          style: TextStyle(
            fontSize: 13,
            fontWeight: FontWeight.bold,
            color: rewardColor,
          )
        ),
      ],
    ),
  );
}
```

## main.dart 핵심 로직

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final prefs = await SharedPreferences.getInstance();
  final hasGoal = prefs.getString('goal_name') != null;

  runApp(MyApp(initialRoute: hasGoal ? '/home' : '/onboarding'));
}
```

## 주의사항
- 투명 시연 버튼 반드시 구현 (우측 상단, 80x80, opacity 0.0)
- 모든 색상 위 hex 코드 정확히 사용
- 배경색 #F5EDD9 전체 통일
- 서버, 로그인, 회원가입 없음
- flutter run -d chrome 으로 로컬 실행
- 캐릭터 이미지 assets/characters/ 에 있음
